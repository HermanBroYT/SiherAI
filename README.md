# Siher AI (Android, v1.0, minSdk 29 = Android 10+)
1. Откройте папку в Android Studio (Koala или новее) → дождитесь Gradle Sync.
2. Run ▶ на устройстве/эмуляторе. Для APK: Build → Build APK(s).
Команды: «Какая погода», «Новости», «Запусти <приложение>», «Позвони <имя/номер>».
Разрешения: уведомления, местоположение, микрофон, контакты (+ звонки для CALL_PHONE).
